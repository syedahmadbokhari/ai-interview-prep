# Changelog

## 0.1.0

- Initial extracted package.
- Added typed public models: `EvidenceItem`, `AssertionResult`,
  `ValidationContext`, and `ValidationResult`.
- Added `AssertionRunner`, `AssertionProtocol`, and `BaseAssertion`.
- Added built-in entity/project, technology, metric, date, and scope assertions.
- Added runnable examples and package tests.
- Added packaging metadata for wheel/sdist builds.
